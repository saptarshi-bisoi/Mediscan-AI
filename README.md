# 🧠 MediScan AI - Brain Tumor Detection

MediScan AI is a web-based application that allows users to upload MRI brain scans and get an AI-powered prediction of whether a brain tumor is present.  

⚠️ **Disclaimer**: This project is for **educational and research purposes only**. Not for medical use.  

---

## 🚀 Tech Stack
- **HTML5, CSS3, JavaScript** – Frontend  
- **Flask (Python)** – Backend (planned)  
- **TensorFlow / Keras** – AI Model (planned)  
---

## ⚡ API Integration

This project uses **Google Gemini API** for AI-powered analysis of brain scan images.  

### 🔑 Setup Instructions

1. Get your **Google Gemini API Key** from [Google AI Studio](https://aistudio.google.com/).
2. Create a `.env` file in the project root and add your key
---

## 🌟 Features
- Upload MRI scan images  
- AI-powered tumor detection (future integration)  
- Simple and responsive UI  
- Educational demo project
